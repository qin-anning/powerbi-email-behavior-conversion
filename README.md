# Power BI 用户行为与邮件转化分析

> 课程项目模拟数据 · Power BI · 用户行为 · 转化漏斗 · A/B 分组分析

## 项目概览

本项目以邮件触达为场景，使用匿名化的课程项目模拟数据，分析用户从“发送”到“打开、回复、完成跟进”的行为链路。项目重点是搭建可复用的指标口径、Power BI 看板和分组对比方法，而非对真实业务效果作出推断。

## 业务问题

- 邮件触达的主要流失发生在哪个环节？
- AI 辅助与人工邮件在打开、回复和跟进转化上是否存在差异？
- 哪些渠道、地区、设备或用户分群需要进一步优化？
- 数据是否存在重复记录、缺失关键字段或不合理的漏斗关系？

## 数据与边界

- 数据文件：`data/email_behavior_sample.csv`
- 粒度：一行代表一次邮件触达（`email_id`），包含用户分群、邮件类型、设备、渠道以及打开/回复/跟进结果。
- 样本规模：480 次邮件触达；数据由脚本按预设规则生成，仅用于课程作品集展示。
- 不包含真实用户、个人信息或企业业务数据。

## 看板设计

### 页面 1：转化总览

- KPI：发送数、打开数、回复数、完成跟进数
- 漏斗：发送 → 打开 → 回复 → 跟进
- 趋势：按周查看打开率、回复率、跟进率
- 筛选器：邮件类型、渠道、地区、设备、用户分群

### 页面 2：AI 与人工邮件对比

- 对比 AI 辅助组与人工组的打开率、回复率、跟进率
- 按渠道与用户分群查看差异
- 仅呈现描述性比较；不将模拟数据解读为因果结论

### 页面 3：分群与数据质量

- 渠道、地区、设备和用户分群的转化热力图
- 重复邮件 ID、关键字段缺失、漏斗逻辑校验
- 标记需要进一步核查的数据记录

## 快速开始

1. 使用 Power BI Desktop 导入 `data/email_behavior_sample.csv`。
2. 将 `powerbi/measures.dax` 中的度量值逐项创建到 `EmailBehavior` 表。
3. 按 `docs/dashboard_spec.md` 搭建三个页面；指标定义见 `docs/metric_dictionary.md`。
4. 可运行 `scripts/generate_sample_data.py` 复现数据集。
