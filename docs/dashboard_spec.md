# 看板搭建说明

## 数据模型

导入 `email_behavior_sample.csv` 并将表命名为 `EmailBehavior`。将 `send_date` 转为日期类型，`opened`、`replied`、`follow_up_completed` 转为整数或布尔类型。

建议新建日期表并与 `EmailBehavior[send_date]` 建立一对多关系；在课程作品中，也可直接使用 `send_date` 按周聚合。

## 页面 1：转化总览

- 卡片：发送数、打开率、回复率、跟进率。
- 漏斗图：发送数、打开数、回复数、完成跟进数。
- 折线图：按 `send_week` 展示打开率、回复率和跟进率。
- 切片器：`email_type`、`channel`、`region`、`device_type`、`user_segment`。

## 页面 2：AI 与人工邮件对比

- 簇状柱状图：按 `email_type` 比较打开率、回复率、跟进率。
- 矩阵：行使用 `user_segment`，列使用 `email_type`，值为跟进率。
- 条形图：按渠道比较两类邮件的打开后回复率。

## 页面 3：分群与数据质量

- 热力图或矩阵：地区 × 设备类型，查看跟进率。
- 条形图：渠道、用户分群的发送数与跟进率。
- 数据质量卡片：重复邮件数、关键字段缺失数、漏斗逻辑异常数。

## 作品集展示建议

- 使用筛选器展示不同分群下的转化变化，并说明观察到的现象是描述性结论。
- 在 README 或汇报页清楚标记“课程项目模拟数据”。
- 若对比两组效果，说明真实业务还需随机分流和显著性检验。
